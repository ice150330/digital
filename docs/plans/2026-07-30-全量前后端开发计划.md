## 方案概述（选定路线）

**依赖铁律：**

```text
分析产物（文件） → 服务门面/API → 前端 → Agent 只读门面
```

- **双轨不变：** CSV 只读真相 → SQLite 主数据查询；模型/metrics/SHAP/分群/规则 → `outputs/` **文件**，**不进** SQLite  
- **内核与 Agent 分离：** 指标只来自产物；Agent 不编造数字  
- **前后端并行窗口：** 前端壳/tokens/7 路由/EmptyState/About **可先做**；业务数字页等对应 API  
- **不做：** P2 默认不开（RAG/K8s/多租户/因果 uplift 主线/Docker 等）；扩大须用户确认  

**业界对齐（借鉴点，不引入重框架）：**

| 借鉴 | 落到本项目 |
|------|------------|
| LightGBM + TreeExplainer SHAP 服务化 | 启动加载 run；`predict`/`explain` 返回 JSON 给 ECharts |
| FastAPI lifespan 加载模型 | `api/deps` 或 registry 单例；缺产物 → `MODEL_NOT_LOADED` |
| Host-executed tools + 审计 | LocalToolRuntime 白名单；`outputs/agent_logs/*.jsonl` |
| 无 Key 可演示 | template/规则路由播报工具 JSON |
| 项目内 CLI 隔离 | `setup_pi_cli` → `tools/pi-cli/`；禁 PATH/`which pi` |

参考实践（方法借鉴，非照搬依赖）：可解释营销转化看板（LightGBM+SHAP+FastAPI+Vue）、工具接地 Agent（function calling + 结构化审计日志）。

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 正类 ~87.65%，Accuracy 虚高 | 答辩被质疑 | 强制 Dummy + PR-AUC 主指标；Accuracy 标对照 |
| CustomerID / ConversionRate 泄漏质疑 | 学术风险 | 永不入模 + E5 消融专节 + 质量报告 |
| SHAP/训练环境装不上 LightGBM | 阻塞 | 回退 RF；TreeExplainer 或替代；预缓存样例 |
